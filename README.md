# 面试题库（云端定时任务）

每个任务只读写自己的目录，互不冲突。

## 目录结构
- `algo/`：算法题（Go，力扣经典题）
- `scenario/`：后端场景题（含设计图和表设计）
- `backend/`：后端知识题（Go / Java / 数据库等）

每个目录内：
- `index.md`：近 3 个月已出题目索引，每题一行，格式：`日期 | 类别 | 主题关键词 | 编号`
- `topics.md`：按主题的覆盖摘要（已覆盖 / 未覆盖），用于选题去重
- `archive/年份-月份.md`：超过 3 个月的旧索引

## 运行规则
1. 读取本目录 `topics.md` 和 `index.md`，避免重复主题。
2. 生成当天题目（每个任务的数量见各自的说明），每题附完整答案。
3. 将当天题目记入 `index.md`。
4. 若 `index.md` 超过 150 行，把 3 个月前的行移入 `archive/当月.md`，并更新 `topics.md`。
5. 提交并推送：`git pull --rebase` 后 `git commit`，再 `git push`。
