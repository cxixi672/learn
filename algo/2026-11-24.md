# 每日算法题 2026-11-24

## 第一题：零钱兑换

- 题号：LeetCode 322
- 链接：https://leetcode.cn/problems/coin-change/
- 编号：algo-20261124-01
- 难度：中等

**题目描述**：给你一个整数数组 coins 表示不同面额的硬币，以及一个整数 amount 表示总金额。计算并返回凑成总金额所需的最少硬币个数；如果没有任何一种硬币组合能组成总金额，返回 -1。每种硬币的数量无限。

示例：输入 coins = [1,2,5], amount = 11，输出 3（11 = 5 + 5 + 1）；输入 coins = [2], amount = 3，输出 -1；输入 coins = [1], amount = 0，输出 0。

**解题思路**

这是典型的完全背包求最小个数问题。核心状态：f(x) 表示凑出金额 x 所需的最少硬币数，转移为 f(x) = min(f(x - c)) + 1，其中 c 遍历每种面额。

| 解法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|---|---|---|---|
| 解法一：暴力递归（指数级） | O(S^n)，S 为金额，n 为硬币种数（最坏） | O(S)（递归栈） | 仅用于建立直觉，金额稍大就会超时，因为大量子问题被重复计算。 |
| 解法二：记忆化搜索（自顶向下 DP） | O(S × n) | O(S) | 思路直观，容易从暴力解改写而来，适合面试中第一个给出可通过的解。 |
| 解法三：自底向上 DP（完全背包，最优） | O(S × n) | O(S) | 常数最小、没有递归开销，是该题的标准解法，也是完全背包问题的模板写法。 |

### 解法一：暴力递归（指数级）

对剩余金额 rem，枚举每一种硬币 c，递归求 rem - c 的最少硬币数，取最小值加 1。rem 为 0 返回 0，rem 小于 0 返回 -1。

```go
package main

import "fmt"

// 解法一：暴力递归（纯 DFS，指数级，仅用于理解）
func coinChange(coins []int, amount int) int {
	var dfs func(rem int) int
	dfs = func(rem int) int {
		if rem == 0 {
			return 0
		}
		if rem < 0 {
			return -1
		}
		best := -1
		for _, c := range coins {
			sub := dfs(rem - c)
			if sub >= 0 && (best == -1 || sub+1 < best) {
				best = sub + 1
			}
		}
		return best
	}
	return dfs(amount)
}

func main() {
	fmt.Println(coinChange([]int{1, 2, 5}, 11), coinChange([]int{2}, 3), coinChange([]int{1}, 0))
}
```

### 解法二：记忆化搜索（自顶向下 DP）

在暴力递归的基础上，用数组 memo 缓存每个金额的结果，每个子问题只计算一次，状态数 S，每个状态枚举 n 种硬币。

```go
package main

import "fmt"

// 解法二：记忆化搜索（自顶向下 DP）
func coinChange(coins []int, amount int) int {
	memo := make([]int, amount+1)
	for i := range memo {
		memo[i] = -2 // -2 表示未计算
	}
	var dfs func(rem int) int
	dfs = func(rem int) int {
		if rem == 0 {
			return 0
		}
		if rem < 0 {
			return -1
		}
		if memo[rem] != -2 {
			return memo[rem]
		}
		best := -1
		for _, c := range coins {
			sub := dfs(rem - c)
			if sub >= 0 && (best == -1 || sub+1 < best) {
				best = sub + 1
			}
		}
		memo[rem] = best
		return best
	}
	return dfs(amount)
}

func main() {
	fmt.Println(coinChange([]int{1, 2, 5}, 11), coinChange([]int{2}, 3), coinChange([]int{1}, 0))
}
```

### 解法三：自底向上 DP（完全背包，最优）

dp[j] 表示凑成 j 的最少硬币数，初始 dp[0] = 0，其余设为 amount + 1（相当于无穷大）。外层遍历硬币，内层从小到大遍历金额（正序保证每种硬币可重复使用）。最后若 dp[amount] 仍为无穷大则返回 -1。

```go
package main

import "fmt"

// 解法三：自底向上 DP（完全背包）
func coinChange(coins []int, amount int) int {
	inf := amount + 1
	dp := make([]int, amount+1)
	for i := 1; i <= amount; i++ {
		dp[i] = inf
	}
	for _, c := range coins {
		for j := c; j <= amount; j++ {
			if dp[j-c]+1 < dp[j] {
				dp[j] = dp[j-c] + 1
			}
		}
	}
	if dp[amount] >= inf {
		return -1
	}
	return dp[amount]
}

func main() {
	fmt.Println(coinChange([]int{1, 2, 5}, 11), coinChange([]int{2}, 3), coinChange([]int{1}, 0))
}
```

## 第二题：数组中的第K个最大元素

- 题号：LeetCode 215
- 链接：https://leetcode.cn/problems/kth-largest-element-in-an-array/
- 编号：algo-20261124-02
- 难度：中等

**题目描述**：给定整数数组 nums 和整数 k，请返回数组中第 k 个最大的元素。注意是排序后的第 k 个最大元素，而不是第 k 个不同的元素。题目要求设计并实现时间复杂度为 O(n) 的算法。

示例：输入 nums = [3,2,1,5,6,4], k = 2，输出 5；输入 nums = [3,2,3,1,2,4,5,5,6], k = 4，输出 4。

**解题思路**

这是 Top K 问题的经典代表，常见三种思路：全排序、堆、快速选择，复杂度依次改善，面试中通常要求讲到堆或快速选择。

| 解法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|---|---|---|---|
| 解法一：排序 | O(n log n) | O(n)（这里复制了一份数组以避免修改原数组） | 代码最短，数据量不大或不要求最优复杂度时首选。 |
| 解法二：大小为 k 的小顶堆 | O(n log k) | O(k) | 适合数据流或数据量极大、无法一次性装入内存的场景，只需维护 k 个元素。 |
| 解法三：快速选择（期望 O(n)，最优） | 期望 O(n)，最坏 O(n²)（随机化 pivot 使最坏情况极难出现） | O(n)（复制数组）；原地操作时为 O(1) | 只需要第 k 大、不需要整体有序时的最优解，满足题目要求的 O(n)。 |

### 解法一：排序

把数组降序排序，下标 k - 1 的元素就是答案。

```go
package main

import (
	"fmt"
	"sort"
)

// 解法一：排序
func findKthLargest(nums []int, k int) int {
	arr := append([]int(nil), nums...)
	sort.Sort(sort.Reverse(sort.IntSlice(arr)))
	return arr[k-1]
}

func main() {
	fmt.Println(findKthLargest([]int{3, 2, 1, 5, 6, 4}, 2), findKthLargest([]int{3, 2, 3, 1, 2, 4, 5, 5, 6}, 4))
}
```

### 解法二：大小为 k 的小顶堆

维护一个容量为 k 的小顶堆，堆顶是当前第 k 大的元素。遍历数组，堆未满则直接入堆；堆满后若新元素大于堆顶，则替换堆顶并下沉。遍历结束后堆顶即为答案。下面是手写堆，不依赖 container/heap，便于面试书写。

```go
package main

import "fmt"

// 解法二：大小为 k 的小顶堆（手写堆）
func findKthLargest(nums []int, k int) int {
	heap := make([]int, 0, k)
	siftUp := func(i int) {
		for i > 0 {
			p := (i - 1) / 2
			if heap[p] <= heap[i] {
				break
			}
			heap[p], heap[i] = heap[i], heap[p]
			i = p
		}
	}
	siftDown := func(i int) {
		n := len(heap)
		for {
			l, r, m := 2*i+1, 2*i+2, i
			if l < n && heap[l] < heap[m] {
				m = l
			}
			if r < n && heap[r] < heap[m] {
				m = r
			}
			if m == i {
				return
			}
			heap[m], heap[i] = heap[i], heap[m]
			i = m
		}
	}
	for _, x := range nums {
		if len(heap) < k {
			heap = append(heap, x)
			siftUp(len(heap) - 1)
		} else if x > heap[0] {
			heap[0] = x
			siftDown(0)
		}
	}
	return heap[0]
}

func main() {
	fmt.Println(findKthLargest([]int{3, 2, 1, 5, 6, 4}, 2), findKthLargest([]int{3, 2, 3, 1, 2, 4, 5, 5, 6}, 4))
}
```

### 解法三：快速选择（期望 O(n)，最优）

第 k 大等价于升序排列中下标 n - k 的元素。随机选 pivot，用三路划分把数组分成小于、等于、大于 pivot 三段；若目标下标落在等于段则直接返回 pivot，否则只递归（迭代）到目标所在的一侧。三路划分能很好地处理大量重复元素。

```go
package main

import (
	"fmt"
	"math/rand"
)

// 解法三：快速选择（三路划分，期望 O(n)）
func findKthLargest(nums []int, k int) int {
	arr := append([]int(nil), nums...)
	target := len(arr) - k // 升序下第 target 小（从 0 计）
	lo, hi := 0, len(arr)-1
	for lo < hi {
		pivot := arr[lo+rand.Intn(hi-lo+1)]
		lt, i, gt := lo, lo, hi
		for i <= gt {
			switch {
			case arr[i] < pivot:
				arr[lt], arr[i] = arr[i], arr[lt]
				lt++
				i++
			case arr[i] > pivot:
				arr[i], arr[gt] = arr[gt], arr[i]
				gt--
			default:
				i++
			}
		}
		// [lo,lt) < pivot, [lt,gt] == pivot, (gt,hi] > pivot
		if target < lt {
			hi = lt - 1
		} else if target > gt {
			lo = gt + 1
		} else {
			return pivot
		}
	}
	return arr[lo]
}

func main() {
	fmt.Println(findKthLargest([]int{3, 2, 1, 5, 6, 4}, 2), findKthLargest([]int{3, 2, 3, 1, 2, 4, 5, 5, 6}, 4))
}
```
