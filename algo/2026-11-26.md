# 每日算法题 2026-11-26

## 第一题：接雨水

- 题号：LeetCode 42
- 链接：https://leetcode.cn/problems/trapping-rain-water/
- 编号：algo-20261126-01
- 难度：困难

**题目描述**：给定 n 个非负整数表示每个宽度为 1 的柱子的高度图 height，计算按此排列的柱子下雨之后能接多少雨水。

示例：输入 height = [0,1,0,2,1,0,1,3,2,1,2,1]，输出 6；输入 height = [4,2,0,3,2,5]，输出 9。

**解题思路**

下标 i 这一列能存的水，等于它左边最高柱子与右边最高柱子中较矮者减去自身高度，即 min(leftMax, rightMax) - height[i]。暴力、前缀数组、双指针都是在用不同代价求这两个最大值；单调栈则换了视角，按水平层一层层地算。

| 解法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|---|---|---|---|
| 解法一：按列暴力 | O(n²) | O(1) | 思路最直接，适合先说清公式；n 较大时会超时。 |
| 解法二：前缀和后缀最大值 | O(n) | O(n) | 空间换时间，代码清晰不易错；需要多次查询每列水量时很合适。 |
| 解法三：单调栈 | O(n) | O(n) | 按层计算，只需从左到右遍历一遍；是柱状图类题目的通用技巧。 |
| 解法四：双指针（最优） | O(n) | O(1) | 面试最优解；依赖数组能从两端同时访问。 |

### 解法一：按列暴力

对每一列分别向左、向右扫描求最大高度（都包含自己，所以结果不会为负），再套公式累加。min 和 max 是 Go 1.21 起的内置函数。

```go
package main

import "fmt"

// 解法一：按列暴力，每列向两侧扫描最高柱子
func trap(height []int) int {
	ans := 0
	for i, h := range height {
		left, right := 0, 0
		for j := 0; j <= i; j++ {
			left = max(left, height[j])
		}
		for j := i; j < len(height); j++ {
			right = max(right, height[j])
		}
		ans += min(left, right) - h
	}
	return ans
}

func main() {
	fmt.Println(trap([]int{0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1})) // 6
	fmt.Println(trap([]int{4, 2, 0, 3, 2, 5}))                   // 9
}
```

### 解法二：前缀和后缀最大值

暴力法反复计算同样的最大值。用 left 数组从左到右递推、right 数组从右到左递推，每列即可 O(1) 结算。

```go
package main

import "fmt"

// 解法二：预处理前缀最大值和后缀最大值
func trap(height []int) int {
	n := len(height)
	left := make([]int, n)  // left[i] 为 [0, i] 内的最大高度
	right := make([]int, n) // right[i] 为 [i, n-1] 内的最大高度
	for i := 0; i < n; i++ {
		left[i] = height[i]
		if i > 0 {
			left[i] = max(left[i-1], height[i])
		}
	}
	for i := n - 1; i >= 0; i-- {
		right[i] = height[i]
		if i < n-1 {
			right[i] = max(right[i+1], height[i])
		}
	}
	ans := 0
	for i, h := range height {
		ans += min(left[i], right[i]) - h
	}
	return ans
}

func main() {
	fmt.Println(trap([]int{0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1})) // 6
	fmt.Println(trap([]int{4, 2, 0, 3, 2, 5}))                   // 9
}
```

### 解法三：单调栈

栈内下标对应的高度单调不增。当前柱子比栈顶高时形成凹槽：弹出栈顶作为槽底，新的栈顶是左边界，当前柱子是右边界，累加宽度乘以深度。每个下标最多入栈、出栈各一次。

```go
package main

import "fmt"

// 解法三：单调栈，按水平层累加雨水
func trap(height []int) int {
	ans := 0
	stack := []int{} // 存下标，对应高度从栈底到栈顶单调不增
	for i, h := range height {
		for len(stack) > 0 && height[stack[len(stack)-1]] < h {
			bottom := stack[len(stack)-1]
			stack = stack[:len(stack)-1]
			if len(stack) == 0 {
				break // 没有左边界，接不住水
			}
			left := stack[len(stack)-1]
			width := i - left - 1
			depth := min(height[left], h) - height[bottom]
			ans += width * depth
		}
		stack = append(stack, i)
	}
	return ans
}

func main() {
	fmt.Println(trap([]int{0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1})) // 6
	fmt.Println(trap([]int{4, 2, 0, 3, 2, 5}))                   // 9
}
```

### 解法四：双指针（最优）

两端指针向中间走。若 leftMax 小于 rightMax，左指针这一列右侧的真实最大值一定不小于 rightMax，水量只由 leftMax 决定，可立即结算并右移；反之处理右指针。

```go
package main

import "fmt"

// 解法四：双指针，哪一侧的最大值更小就结算哪一侧
func trap(height []int) int {
	l, r := 0, len(height)-1
	leftMax, rightMax, ans := 0, 0, 0
	for l < r {
		leftMax = max(leftMax, height[l])
		rightMax = max(rightMax, height[r])
		if leftMax < rightMax {
			ans += leftMax - height[l]
			l++
		} else {
			ans += rightMax - height[r]
			r--
		}
	}
	return ans
}

func main() {
	fmt.Println(trap([]int{0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1})) // 6
	fmt.Println(trap([]int{4, 2, 0, 3, 2, 5}))                   // 9
}
```

## 第二题：二叉树的最近公共祖先

- 题号：LeetCode 236
- 链接：https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/
- 编号：algo-20261126-02
- 难度：中等

**题目描述**：给定一个二叉树和树中的两个节点 p、q，找到它们的最近公共祖先，即深度尽可能大、且同时是 p 和 q 祖先的节点（一个节点也可以是它自己的祖先）。节点值互不相同，p 与 q 不同且都存在于树中。

示例：root = [3,5,1,6,2,0,8,null,null,7,4]。p = 5，q = 1 时输出 3；p = 5，q = 4 时输出 5。

**解题思路**

最近公共祖先就是 p、q 路径的分叉点：要么两者分别位于它的左右子树，要么它本身就是 p 或 q 且另一个在它下面。可以自顶向下反复查找分叉点，也可以记录父节点向上走，最优做法是一次后序遍历让子树把结果带回来。

| 解法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|---|---|---|---|
| 解法一：自顶向下查找（暴力） | 最坏 O(n²) | O(h) | 树较平衡或很小时可用；退化成链表时重复遍历严重。 |
| 解法二：父指针加哈希表 | O(n) | O(n) | 同一棵树要查询多次时，父节点表只需建一次；迭代遍历，不依赖递归深度。 |
| 解法三：一次后序遍历（最优） | O(n) | O(h) | 面试标准答案，代码最短；前提是 p、q 一定都在树中。 |

### 解法一：自顶向下查找（暴力）

在当前节点判断 p、q 是否在左子树：都在就往左走，都不在就往右走，否则当前节点即答案。h 为树高，是递归栈开销。平衡树上约为 O(n)。

```go
package main

import "fmt"

type TreeNode struct {
	Val   int
	Left  *TreeNode
	Right *TreeNode
}

// contains 判断以 root 为根的子树里是否有 target
func contains(root, target *TreeNode) bool {
	if root == nil {
		return false
	}
	return root == target || contains(root.Left, target) || contains(root.Right, target)
}

// 解法一：自顶向下查找分叉点
func lowestCommonAncestor(root, p, q *TreeNode) *TreeNode {
	if root == nil || root == p || root == q {
		return root
	}
	pInLeft := contains(root.Left, p)
	qInLeft := contains(root.Left, q)
	if pInLeft && qInLeft {
		return lowestCommonAncestor(root.Left, p, q)
	}
	if !pInLeft && !qInLeft {
		return lowestCommonAncestor(root.Right, p, q)
	}
	return root // p 和 q 分居两侧
}

func main() {
	n := make([]*TreeNode, 9) // n[i] 是值为 i 的节点
	for i := range n {
		n[i] = &TreeNode{Val: i}
	}
	link := func(p, l, r int) { n[p].Left, n[p].Right = n[l], n[r] }
	link(3, 5, 1)
	link(5, 6, 2)
	link(1, 0, 8)
	link(2, 7, 4)
	fmt.Println(lowestCommonAncestor(n[3], n[5], n[1]).Val) // 3
	fmt.Println(lowestCommonAncestor(n[3], n[5], n[4]).Val) // 5
}
```

### 解法二：父指针加哈希表

先遍历整棵树记录每个节点的父节点。从 p 一路向上标记祖先，再从 q 向上走，第一个被标记过的节点就是答案。本题中建表 O(n)，之后每次查询 O(h)（代码为单次查询写法）。

```go
package main

import "fmt"

type TreeNode struct {
	Val   int
	Left  *TreeNode
	Right *TreeNode
}

// 解法二：记录父节点，把问题转成两条链表求交点
func lowestCommonAncestor(root, p, q *TreeNode) *TreeNode {
	parent := map[*TreeNode]*TreeNode{root: nil}
	stack := []*TreeNode{root}
	for len(stack) > 0 {
		node := stack[len(stack)-1]
		stack = stack[:len(stack)-1]
		for _, child := range []*TreeNode{node.Left, node.Right} {
			if child != nil {
				parent[child] = node
				stack = append(stack, child)
			}
		}
	}
	visited := map[*TreeNode]bool{}
	for x := p; x != nil; x = parent[x] {
		visited[x] = true
	}
	for x := q; x != nil; x = parent[x] {
		if visited[x] {
			return x
		}
	}
	return nil
}

func main() {
	n := make([]*TreeNode, 9) // n[i] 是值为 i 的节点
	for i := range n {
		n[i] = &TreeNode{Val: i}
	}
	link := func(p, l, r int) { n[p].Left, n[p].Right = n[l], n[r] }
	link(3, 5, 1)
	link(5, 6, 2)
	link(1, 0, 8)
	link(2, 7, 4)
	fmt.Println(lowestCommonAncestor(n[3], n[5], n[1]).Val) // 3
	fmt.Println(lowestCommonAncestor(n[3], n[5], n[4]).Val) // 5
}
```

### 解法三：一次后序遍历（最优）

遇到空节点、p 或 q 直接返回。分别递归左右子树：两边都非空说明当前节点是分叉点；只有一边非空就把那一边的结果向上传。最坏情况下 h 等于 n。

```go
package main

import "fmt"

type TreeNode struct {
	Val   int
	Left  *TreeNode
	Right *TreeNode
}

// 解法三：一次后序遍历
// 返回值含义：子树中找到的 p、q 或它们的最近公共祖先，都没有则为 nil
func lowestCommonAncestor(root, p, q *TreeNode) *TreeNode {
	if root == nil || root == p || root == q {
		return root
	}
	left := lowestCommonAncestor(root.Left, p, q)
	right := lowestCommonAncestor(root.Right, p, q)
	if left != nil && right != nil {
		return root // 左右各找到一个
	}
	if left != nil {
		return left
	}
	return right
}

func main() {
	n := make([]*TreeNode, 9) // n[i] 是值为 i 的节点
	for i := range n {
		n[i] = &TreeNode{Val: i}
	}
	link := func(p, l, r int) { n[p].Left, n[p].Right = n[l], n[r] }
	link(3, 5, 1)
	link(5, 6, 2)
	link(1, 0, 8)
	link(2, 7, 4)
	fmt.Println(lowestCommonAncestor(n[3], n[5], n[1]).Val) // 3
	fmt.Println(lowestCommonAncestor(n[3], n[5], n[4]).Val) // 5
}
```
