# 每日算法题 2026-11-25

## 第一题：搜索旋转排序数组

- 题号：LeetCode 33
- 链接：https://leetcode.cn/problems/search-in-rotated-sorted-array/
- 编号：algo-20261125-01
- 难度：中等

**题目描述**：整数数组 nums 按升序排列，数组中的值互不相同。nums 在某个未知下标 k 处发生了旋转，变为 [nums[k], nums[k+1], ..., nums[n-1], nums[0], ..., nums[k-1]]。给你旋转后的数组 nums 和一个整数 target，如果 nums 中存在 target 则返回它的下标，否则返回 -1。要求时间复杂度为 O(log n)。

示例：输入 nums = [4,5,6,7,0,1,2]，target = 0，输出 4；输入 nums = [4,5,6,7,0,1,2]，target = 3，输出 -1；输入 nums = [1]，target = 0，输出 -1。

**解题思路**

旋转后的数组可以看成两段各自有序的子数组。关键观察：任取中点 mid，把数组一分为二，则其中至少有一半一定是有序的。利用这一点，每轮都能判断 target 是否落在有序的那一半，从而丢掉一半区间，保持对数复杂度。

| 解法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|---|---|---|---|
| 解法一：线性扫描 | O(n) | O(1) | 不满足题目 O(log n) 要求，只能作为基线；数据量很小或需要先验证正确性时可用。 |
| 解法二：先找旋转点，再二分 | O(log n) | O(1) | 思路清晰，把问题拆成找最小值和普通二分两个已知模板；两次二分，代码稍长。 |
| 解法三：一次二分（最优） | O(log n) | O(1) | 面试标准答案，只扫一遍，每轮判断哪一半有序再缩小区间；注意边界使用 nums[lo] <= nums[mid]。 |

### 解法一：线性扫描

直接遍历数组比较每个元素，完全不利用有序性。复杂度 O(n)，不满足题目要求，但可作为对拍用的基准实现。

```go
package main

import "fmt"

// 解法一：线性扫描，忽略有序性
func search(nums []int, target int) int {
	for i, v := range nums {
		if v == target {
			return i
		}
	}
	return -1
}

func main() {
	fmt.Println(search([]int{4, 5, 6, 7, 0, 1, 2}, 0)) // 4
	fmt.Println(search([]int{4, 5, 6, 7, 0, 1, 2}, 3)) // -1
	fmt.Println(search([]int{1}, 0))                    // -1
}
```

### 解法二：先找旋转点，再二分

第一次二分比较 nums[mid] 与 nums[hi]：若 nums[mid] 更大，说明最小值在右侧，否则在 mid 及其左侧，最终得到最小值下标 pivot。然后根据 target 与 nums[pivot]、nums[n-1] 的大小关系，决定在 [pivot, n-1] 还是 [0, pivot-1] 内做普通二分。

```go
package main

import "fmt"

// 解法二：先二分找旋转点（最小值下标），再在有序段内二分
func search(nums []int, target int) int {
	n := len(nums)
	if n == 0 {
		return -1
	}
	// 找最小值下标
	lo, hi := 0, n-1
	for lo < hi {
		mid := lo + (hi-lo)/2
		if nums[mid] > nums[hi] {
			lo = mid + 1
		} else {
			hi = mid
		}
	}
	pivot := lo
	// 判断目标在哪一段
	l, r := 0, n-1
	if target >= nums[pivot] && target <= nums[n-1] {
		l = pivot
	} else {
		r = pivot - 1
	}
	for l <= r {
		mid := l + (r-l)/2
		if nums[mid] == target {
			return mid
		} else if nums[mid] < target {
			l = mid + 1
		} else {
			r = mid - 1
		}
	}
	return -1
}

func main() {
	fmt.Println(search([]int{4, 5, 6, 7, 0, 1, 2}, 0)) // 4
	fmt.Println(search([]int{4, 5, 6, 7, 0, 1, 2}, 3)) // -1
	fmt.Println(search([]int{1}, 0))                    // -1
	fmt.Println(search([]int{1, 3}, 3))                 // 1
}
```

### 解法三：一次二分（最优）

每次取 mid，若 nums[lo] <= nums[mid]，说明左半段 [lo, mid] 有序：target 落在 [nums[lo], nums[mid]) 内就收缩到左半，否则去右半。反之右半段 [mid, hi] 有序，同理判断。每轮至少丢掉一半，总共 O(log n) 轮。

```go
package main

import "fmt"

// 解法三：一次二分，每轮判断哪一半是有序的
func search(nums []int, target int) int {
	lo, hi := 0, len(nums)-1
	for lo <= hi {
		mid := lo + (hi-lo)/2
		if nums[mid] == target {
			return mid
		}
		if nums[lo] <= nums[mid] { // 左半段有序
			if nums[lo] <= target && target < nums[mid] {
				hi = mid - 1
			} else {
				lo = mid + 1
			}
		} else { // 右半段有序
			if nums[mid] < target && target <= nums[hi] {
				lo = mid + 1
			} else {
				hi = mid - 1
			}
		}
	}
	return -1
}

func main() {
	fmt.Println(search([]int{4, 5, 6, 7, 0, 1, 2}, 0)) // 4
	fmt.Println(search([]int{4, 5, 6, 7, 0, 1, 2}, 3)) // -1
	fmt.Println(search([]int{1}, 0))                    // -1
	fmt.Println(search([]int{3, 1}, 1))                 // 1
}
```

## 第二题：环形链表 II

- 题号：LeetCode 142
- 链接：https://leetcode.cn/problems/linked-list-cycle-ii/
- 编号：algo-20261125-02
- 难度：中等

**题目描述**：给定一个链表的头节点 head，返回链表开始入环的第一个节点。如果链表无环，则返回 nil。链表中的环是指链表中某个节点可以通过连续跟踪 next 指针再次到达。不允许修改链表。

示例：输入 head = [3,2,0,-4]，尾节点连回下标 1 的节点，输出入环节点值 2；输入 head = [1,2]，无环，输出 nil；输入 head = [1]，尾节点连回下标 0，输出入环节点值 1。

**解题思路**

先想判断有没有环，再想环的入口在哪。最直接的办法是记录走过的节点，更进一步可以用 Floyd 判圈法，在 O(1) 额外空间下找到入口。设头到入环点距离为 a，入环点到相遇点距离为 b，环长为 c。快指针速度是慢指针两倍，相遇时有 2(a+b) = a+b+nc，化简得 a = nc - b，即从相遇点再走 a 步恰好回到入环点，因此头节点出发的指针与相遇点出发的指针同速前进，会在入环点相遇。

| 解法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|---|---|---|---|
| 解法一：哈希表 | O(n) | O(n) | 最直观，适合快速写出正确解；链表很长时额外空间较大。 |
| 解法二：Floyd 快慢指针（最优） | O(n) | O(1) | 面试标准答案，常数空间；需要能口述 a = nc - b 的推导。 |
| 解法三：先求环长，再前后指针 | O(n) | O(1) | 不依赖推导 a = nc - b，思路更好理解：前指针先走环长步，再与后指针同速前进必在入口相遇；适合作为备选讲解。 |

### 解法一：哈希表

从头遍历，用 map 记录每个已访问的节点指针；遍历中若遇到已记录的节点，它就是入环点；遍历到 nil 说明无环。

```go
package main

import "fmt"

type ListNode struct {
	Val  int
	Next *ListNode
}

// 解法一：哈希表记录访问过的节点，第一个重复出现的节点即入环点
func detectCycle(head *ListNode) *ListNode {
	seen := make(map[*ListNode]struct{})
	for p := head; p != nil; p = p.Next {
		if _, ok := seen[p]; ok {
			return p
		}
		seen[p] = struct{}{}
	}
	return nil
}

func build(vals []int, pos int) *ListNode {
	dummy := &ListNode{}
	nodes := make([]*ListNode, 0, len(vals))
	cur := dummy
	for _, v := range vals {
		cur.Next = &ListNode{Val: v}
		cur = cur.Next
		nodes = append(nodes, cur)
	}
	if pos >= 0 {
		cur.Next = nodes[pos]
	}
	return dummy.Next
}

func main() {
	if n := detectCycle(build([]int{3, 2, 0, -4}, 1)); n != nil {
		fmt.Println(n.Val) // 2
	}
	fmt.Println(detectCycle(build([]int{1, 2}, -1)) == nil) // true
	if n := detectCycle(build([]int{1}, 0)); n != nil {
		fmt.Println(n.Val) // 1
	}
}
```

### 解法二：Floyd 快慢指针（最优）

慢指针每次走一步，快指针每次走两步。若二者相遇，说明有环；此时让一个指针回到 head，两个指针都每次走一步，再次相遇的节点就是入环点。

```go
package main

import "fmt"

type ListNode struct {
	Val  int
	Next *ListNode
}

// 解法二：Floyd 快慢指针。相遇后一个指针回到头节点，两者同速前进，再次相遇处即入环点
func detectCycle(head *ListNode) *ListNode {
	slow, fast := head, head
	for fast != nil && fast.Next != nil {
		slow = slow.Next
		fast = fast.Next.Next
		if slow == fast {
			p := head
			for p != slow {
				p = p.Next
				slow = slow.Next
			}
			return p
		}
	}
	return nil
}

func build(vals []int, pos int) *ListNode {
	dummy := &ListNode{}
	nodes := make([]*ListNode, 0, len(vals))
	cur := dummy
	for _, v := range vals {
		cur.Next = &ListNode{Val: v}
		cur = cur.Next
		nodes = append(nodes, cur)
	}
	if pos >= 0 {
		cur.Next = nodes[pos]
	}
	return dummy.Next
}

func main() {
	if n := detectCycle(build([]int{3, 2, 0, -4}, 1)); n != nil {
		fmt.Println(n.Val) // 2
	}
	fmt.Println(detectCycle(build([]int{1, 2}, -1)) == nil) // true
	if n := detectCycle(build([]int{1}, 0)); n != nil {
		fmt.Println(n.Val) // 1
	}
}
```

### 解法三：先求环长，再前后指针

快慢指针相遇后，从相遇点绕环一周数出环长 k。然后让前指针从 head 先走 k 步，后指针从 head 出发，两者同速前进，前指针恰好在入口追上后指针（因为前指针到达入口时，已领先 k 步，正好绕环一圈回到入口）。

```go
package main

import "fmt"

type ListNode struct {
	Val  int
	Next *ListNode
}

// 解法三：先用快慢指针判环并求出环长 k，再让前指针先走 k 步，
// 前后指针同速前进，相遇点即入环点
func detectCycle(head *ListNode) *ListNode {
	slow, fast := head, head
	k := 0
	for fast != nil && fast.Next != nil {
		slow = slow.Next
		fast = fast.Next.Next
		if slow == fast {
			// 统计环长
			k = 1
			for p := slow.Next; p != slow; p = p.Next {
				k++
			}
			break
		}
	}
	if k == 0 {
		return nil
	}
	front, back := head, head
	for i := 0; i < k; i++ {
		front = front.Next
	}
	for front != back {
		front = front.Next
		back = back.Next
	}
	return back
}

func build(vals []int, pos int) *ListNode {
	dummy := &ListNode{}
	nodes := make([]*ListNode, 0, len(vals))
	cur := dummy
	for _, v := range vals {
		cur.Next = &ListNode{Val: v}
		cur = cur.Next
		nodes = append(nodes, cur)
	}
	if pos >= 0 {
		cur.Next = nodes[pos]
	}
	return dummy.Next
}

func main() {
	if n := detectCycle(build([]int{3, 2, 0, -4}, 1)); n != nil {
		fmt.Println(n.Val) // 2
	}
	fmt.Println(detectCycle(build([]int{1, 2}, -1)) == nil) // true
	if n := detectCycle(build([]int{1}, 0)); n != nil {
		fmt.Println(n.Val) // 1
	}
}
```
