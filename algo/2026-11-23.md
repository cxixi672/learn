# 每日算法题 2026-11-23

## 第一题：无重复字符的最长子串

- 题号：LeetCode 3
- 链接：https://leetcode.cn/problems/longest-substring-without-repeating-characters/
- 编号：algo-20261123-01
- 难度：中等

**题目描述**：给定一个字符串 `s`，请找出其中不含有重复字符的最长子串的长度。

示例：输入 `s = "abcabcbb"`，输出 `3`（子串 "abc"）；输入 `s = "bbbbb"`，输出 `1`。

**解题思路**

第一种做法是暴力枚举。枚举所有子串的起点和终点，对每个子串用哈希集合判断是否有重复字符。时间复杂度 O(n³)，空间复杂度 O(n)。n 较小时可用，但面试中不宜直接提交。

第二种做法是滑动窗口加哈希表计数。右指针 `r` 不断向右扩展窗口，窗口内某字符出现次数超过 1 时，左指针 `l` 向右收缩直到重复消除。每个字符最多被加入和移出窗口各一次，时间复杂度 O(n)，空间复杂度 O(字符集大小)。

第三种做法是在滑动窗口基础上优化。记录每个字符上一次出现的位置，遇到重复字符时直接把左边界跳到其上次出现位置之后，无需逐个收缩。用定长数组代替哈希表（ASCII 字符集只有 256 个），时间复杂度 O(n)，空间复杂度 O(1)。

**适用场景**：这类"连续区间 + 满足某条件求最值"的问题都适合滑动窗口。面试中建议先说出暴力解，再讲滑动窗口，最后提出数组优化。

### 解法一：暴力枚举（O(n³)）

```go
func maxInt(a, b int) int {
	if a > b {
		return a
	}
	return b
}

func lengthOfLongestSubstring1(s string) int {
	ans := 0
	for i := 0; i < len(s); i++ {
		for j := i; j < len(s); j++ {
			if allUnique(s, i, j) {
				ans = maxInt(ans, j-i+1)
			}
		}
	}
	return ans
}

func allUnique(s string, l, r int) bool {
	seen := make(map[byte]bool)
	for k := l; k <= r; k++ {
		if seen[s[k]] {
			return false
		}
		seen[s[k]] = true
	}
	return true
}
```

### 解法二：滑动窗口 + 哈希表（O(n)）

```go
func lengthOfLongestSubstring2(s string) int {
	window := make(map[byte]int)
	ans, l := 0, 0
	for r := 0; r < len(s); r++ {
		window[s[r]]++
		for window[s[r]] > 1 {
			window[s[l]]--
			l++
		}
		ans = maxInt(ans, r-l+1)
	}
	return ans
}
```

### 解法三：滑动窗口 + 记录上次位置（O(n)，O(1) 空间）

```go
func lengthOfLongestSubstring3(s string) int {
	var last [256]int // last[c] = 字符 c 上一次出现的下标 + 1
	ans, l := 0, 0
	for r := 0; r < len(s); r++ {
		c := s[r]
		if last[c] > l {
			l = last[c]
		}
		last[c] = r + 1
		ans = maxInt(ans, r-l+1)
	}
	return ans
}
```

## 第二题：岛屿数量

- 题号：LeetCode 200
- 链接：https://leetcode.cn/problems/number-of-islands/
- 编号：algo-20261123-02
- 难度：中等

**题目描述**：给你一个由 `'1'`（陆地）和 `'0'`（水）组成的二维网格，请计算网格中岛屿的数量。岛屿由水平或竖直方向上相邻的陆地连接而成，网格四周都被水包围。

示例：
```
11110
11010
11000
00000
```
输出 `1`。

**解题思路**

第一种做法是深度优先搜索（DFS）。遍历网格，遇到陆地就计数一次，然后从该点出发递归地把整座岛"沉没"（改为 `'0'`），避免重复计数。时间复杂度 O(MN)，空间复杂度 O(MN)（最坏情况下递归栈深度可达 MN）。

第二种做法是广度优先搜索（BFS）。思路与 DFS 相同，只是用显式队列代替递归，逐层向外扩散。时间复杂度 O(MN)，空间复杂度 O(MN)，但避免了递归过深的风险，网格很大时更稳妥。

第三种做法是并查集。把每块陆地看作一个节点，相邻的两块陆地合并到同一集合，初始时每块陆地各自为一个集合。最终集合的数量就是岛屿数量。时间复杂度 O(MN·α(MN))，α 为反阿克曼函数，可视为常数。空间复杂度 O(MN)。这种方法不修改输入网格，并且容易扩展到"动态增加陆地、实时查询岛屿数"的变体题。

**适用场景**：网格连通块计数是经典的图论问题。面试中 DFS 或 BFS 通常足够；若面试官追问"动态添加陆地"或"不能修改输入"，就引出并查集。

> 注意：解法一、二会把输入网格原地改为 `'0'`。如果题目要求保留原数组，应改用 `visited` 数组或使用并查集。

### 解法一：DFS（递归，原地染色）

```go
func numIslands1(grid [][]byte) int {
	count := 0
	for i := range grid {
		for j := range grid[i] {
			if grid[i][j] == '1' {
				count++
				dfs(grid, i, j)
			}
		}
	}
	return count
}

func dfs(grid [][]byte, i, j int) {
	if i < 0 || i >= len(grid) || j < 0 || j >= len(grid[0]) || grid[i][j] != '1' {
		return
	}
	grid[i][j] = '0'
	dfs(grid, i+1, j)
	dfs(grid, i-1, j)
	dfs(grid, i, j+1)
	dfs(grid, i, j-1)
}
```

### 解法二：BFS（队列，原地染色）

```go
type point struct{ r, c int }

func numIslands2(grid [][]byte) int {
	m, n := len(grid), len(grid[0])
	dirs := [4][2]int{{1, 0}, {-1, 0}, {0, 1}, {0, -1}}
	count := 0
	for i := 0; i < m; i++ {
		for j := 0; j < n; j++ {
			if grid[i][j] != '1' {
				continue
			}
			count++
			grid[i][j] = '0'
			queue := []point{{i, j}}
			for len(queue) > 0 {
				p := queue[0]
				queue = queue[1:]
				for _, d := range dirs {
					r, c := p.r+d[0], p.c+d[1]
					if r >= 0 && r < m && c >= 0 && c < n && grid[r][c] == '1' {
						grid[r][c] = '0'
						queue = append(queue, point{r, c})
					}
				}
			}
		}
	}
	return count
}
```

### 解法三：并查集（不修改输入）

```go
type unionFind struct {
	parent []int
	rank   []int
	count  int
}

func newUnionFind(size int) *unionFind {
	uf := &unionFind{parent: make([]int, size), rank: make([]int, size)}
	for i := range uf.parent {
		uf.parent[i] = i
	}
	return uf
}

func (u *unionFind) find(x int) int {
	for u.parent[x] != x {
		u.parent[x] = u.parent[u.parent[x]] // 路径减半压缩
		x = u.parent[x]
	}
	return x
}

func (u *unionFind) union(x, y int) {
	rx, ry := u.find(x), u.find(y)
	if rx == ry {
		return
	}
	if u.rank[rx] < u.rank[ry] {
		rx, ry = ry, rx
	}
	u.parent[ry] = rx
	if u.rank[rx] == u.rank[ry] {
		u.rank[rx]++
	}
	u.count--
}

func numIslands3(grid [][]byte) int {
	m, n := len(grid), len(grid[0])
	uf := newUnionFind(m * n)
	for i := 0; i < m; i++ {
		for j := 0; j < n; j++ {
			if grid[i][j] != '1' {
				continue
			}
			uf.count++
			if i+1 < m && grid[i+1][j] == '1' {
				uf.union(i*n+j, (i+1)*n+j)
			}
			if j+1 < n && grid[i][j+1] == '1' {
				uf.union(i*n+j, i*n+j+1)
			}
		}
	}
	return uf.count
}
```
