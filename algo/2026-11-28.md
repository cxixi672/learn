# 每日算法题 2026-11-28

## 第一题：最长递增子序列

- 题号：LeetCode 300
- 链接：https://leetcode.cn/problems/longest-increasing-subsequence/
- 编号：algo-20261128-01
- 难度：中等

**题目描述**：给定一个整数数组 nums，返回其中最长严格递增子序列的长度。子序列是删除若干（或零个）元素且不改变其余元素相对顺序得到的序列，不要求连续。

示例：输入 [10,9,2,5,3,7,101,18]，输出 4（例如 [2,3,7,101]）；输入 [0,1,0,3,2,3]，输出 4；输入 [7,7,7,7]，输出 1。

数据范围：1 ≤ n ≤ 2500，-10⁴ ≤ nums[i] ≤ 10⁴。进阶要求：O(n log n)。

**解题思路**

先枚举每个元素选或不选；发现大量子问题重复后，把状态定义为“以某个元素结尾”，得到动态规划；再换一个角度，对每种长度只保留最小的结尾元素，这个数组天然有序，于是可以二分。

| 解法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|---|---|---|---|
| 解法一：递归枚举（暴力） | O(2ⁿ) | O(n) | n 在 20 左右时可用，用于理解搜索树或对拍；本题会超时。 |
| 解法二：动态规划 | O(n²) | O(n) | n 为几千时足够；容易扩展到求方案数、带权版本和还原路径。 |
| 解法三：贪心加二分（最优） | O(n log n) | O(n) | n 达到十万级时使用；直接得到长度，还原序列需额外记录前驱。 |

### 解法一：递归枚举（暴力）

dfs(i, prev) 表示从下标 i 开始、上一个选中下标为 prev 时最多还能选几个。每个元素分“不选”和“可以接上就选”两个分支，数组严格递增时会展开约 2ⁿ 个分支。若对 (i, prev) 做记忆化，时间降到 O(n²)，但空间也是 O(n²)，下一种解法把状态压到一维。

```go
package main

import "fmt"

// 解法一：对每个元素决定选或不选，枚举所有递增子序列
func lengthOfLIS(nums []int) int {
	// dfs(i, prev)：从下标 i 开始，上一个选中元素的下标为 prev（-1 表示还没选）
	var dfs func(i, prev int) int
	dfs = func(i, prev int) int {
		if i == len(nums) {
			return 0
		}
		best := dfs(i+1, prev) // 不选 nums[i]
		if prev == -1 || nums[i] > nums[prev] {
			best = max(best, 1+dfs(i+1, i)) // 选 nums[i]
		}
		return best
	}
	return dfs(0, -1)
}

func main() {
	fmt.Println(lengthOfLIS([]int{10, 9, 2, 5, 3, 7, 101, 18})) // 4
	fmt.Println(lengthOfLIS([]int{7, 7, 7, 7}))                 // 1
}
```

### 解法二：动态规划

dp[i] 为以 nums[i] 结尾的最长递增子序列长度。枚举它前面所有更小的 nums[j]，转移为 dp[i] = max(dp[j]) + 1，没有可接的元素时为 1。易错点：答案是整个 dp 数组的最大值，不是最后一项；严格递增必须用小于号。

```go
package main

import "fmt"

// 解法二：dp[i] 表示以 nums[i] 结尾的最长递增子序列长度
func lengthOfLIS(nums []int) int {
	dp := make([]int, len(nums))
	ans := 0
	for i, x := range nums {
		dp[i] = 1 // 只选自己
		for j := 0; j < i; j++ {
			if nums[j] < x { // 严格递增，x 可以接在 nums[j] 后面
				dp[i] = max(dp[i], dp[j]+1)
			}
		}
		ans = max(ans, dp[i]) // 答案不一定以最后一个元素结尾
	}
	return ans
}

func main() {
	fmt.Println(lengthOfLIS([]int{10, 9, 2, 5, 3, 7, 101, 18})) // 4
	fmt.Println(lengthOfLIS([]int{7, 7, 7, 7}))                 // 1
}
```

### 解法三：贪心加二分（最优）

长度相同的递增子序列，结尾越小越容易接长。tails[k] 保存长度 k+1 的最小结尾，它一定严格递增：长度 k+1 的序列去掉末尾，就得到一个结尾更小的长度 k 序列。对每个 x 找第一个大于等于 x 的位置，找到就替换，否则追加。

手推 [10,9,2,5,3,7,101,18]：tails 依次为 [10]、[9]、[2]、[2,5]、[2,3]、[2,3,7]、[2,3,7,101]、[2,3,7,18]，长度 4。

易错点：tails 不一定是真实的子序列，例如 [2,5,1] 最后得到 [1,5]。若改求最长不下降子序列，应查找第一个大于 x 的位置。

```go
package main

import (
	"fmt"
	"sort"
)

// 解法三：贪心 + 二分
// tails[k] 表示长度为 k+1 的递增子序列中，最小的结尾元素
func lengthOfLIS(nums []int) int {
	tails := []int{}
	for _, x := range nums {
		i := sort.SearchInts(tails, x) // 第一个大于等于 x 的位置
		if i == len(tails) {
			tails = append(tails, x) // x 比所有结尾都大，长度加一
		} else {
			tails[i] = x // 用更小的结尾替换，给后面留出空间
		}
	}
	return len(tails)
}

func main() {
	fmt.Println(lengthOfLIS([]int{10, 9, 2, 5, 3, 7, 101, 18})) // 4
	fmt.Println(lengthOfLIS([]int{7, 7, 7, 7}))                 // 1
}
```

## 第二题：合并 K 个升序链表

- 题号：LeetCode 23
- 链接：https://leetcode.cn/problems/merge-k-sorted-lists/
- 编号：algo-20261128-02
- 难度：困难

**题目描述**：给定一个链表数组，每个链表都已按升序排列。把所有链表合并为一个升序链表，返回头节点。

示例：输入 [[1,4,5],[1,3,4],[2,6]]，输出 [1,1,2,3,4,4,5,6]；输入 []，输出 []；输入 [[]]，输出 []。

数据范围：0 ≤ k ≤ 10⁴，单个链表长度 0 到 500，节点值 -10⁴ 到 10⁴，节点总数不超过 10⁴。

**解题思路**

记 k 为链表条数，N 为节点总数。最朴素的做法忽略有序性，全部取出排序；利用有序性可以两两合并，但顺序合并会反复遍历结果链表；改为分治让每个节点只参与约 log k 次合并，或用小根堆每次在 k 个表头中取最小值。

| 解法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|---|---|---|---|
| 解法一：收集后排序（暴力） | O(N log N) | O(N) | 数据量小、需要快速写出；没有利用链表有序，还新建了节点。 |
| 解法二：顺序两两合并 | O(N·k) | O(1) | k 很小时简单实用；k 大时靠前的节点被反复遍历。 |
| 解法三：分治合并（最优） | O(N log k) | O(log k) | 数据都在内存且想节省空间；左右两半可以并行处理。 |
| 解法四：小根堆（最优） | O(N log k) | O(k) | 多路归并通用模板，适合数据流、外部排序中合并多个有序文件。 |

### 解法一：收集后排序（暴力）

遍历所有链表把值放进切片，排序后重新建链表。代码最短，但面试时应主动指出它浪费了“各链表已有序”这个条件。

```go
package main

import (
	"fmt"
	"sort"
)

type ListNode struct {
	Val  int
	Next *ListNode
}

// 解法一：取出所有节点值，排序后重建链表
func mergeKLists(lists []*ListNode) *ListNode {
	vals := []int{}
	for _, p := range lists {
		for ; p != nil; p = p.Next {
			vals = append(vals, p.Val)
		}
	}
	sort.Ints(vals)
	return build(vals)
}

// 辅助函数：由切片建链表
func build(nums []int) *ListNode {
	dummy := &ListNode{}
	tail := dummy
	for _, x := range nums {
		tail.Next = &ListNode{Val: x}
		tail = tail.Next
	}
	return dummy.Next
}

// 辅助函数：打印链表
func show(head *ListNode) {
	res := []int{}
	for ; head != nil; head = head.Next {
		res = append(res, head.Val)
	}
	fmt.Println(res)
}

func main() {
	lists := []*ListNode{
		build([]int{1, 4, 5}),
		build([]int{1, 3, 4}),
		build([]int{2, 6}),
	}
	show(mergeKLists(lists)) // [1 1 2 3 4 4 5 6]
}
```

### 解法二：顺序两两合并

先掌握合并两个有序链表（力扣 21），再把每条链表依次并入结果。若 k 条链表长度都是 n，总代价约为 n·(1+2+…+k)，即 O(N·k)。

```go
package main

import "fmt"

type ListNode struct {
	Val  int
	Next *ListNode
}

// 合并两个升序链表，复用原节点
func mergeTwo(a, b *ListNode) *ListNode {
	dummy := &ListNode{}
	tail := dummy
	for a != nil && b != nil {
		if a.Val <= b.Val {
			tail.Next, a = a, a.Next
		} else {
			tail.Next, b = b, b.Next
		}
		tail = tail.Next
	}
	if a != nil {
		tail.Next = a // 接上剩余部分
	} else {
		tail.Next = b
	}
	return dummy.Next
}

// 解法二：把链表依次合并到结果上
func mergeKLists(lists []*ListNode) *ListNode {
	var res *ListNode
	for _, p := range lists {
		res = mergeTwo(res, p)
	}
	return res
}

// 辅助函数：由切片建链表
func build(nums []int) *ListNode {
	dummy := &ListNode{}
	tail := dummy
	for _, x := range nums {
		tail.Next = &ListNode{Val: x}
		tail = tail.Next
	}
	return dummy.Next
}

// 辅助函数：打印链表
func show(head *ListNode) {
	res := []int{}
	for ; head != nil; head = head.Next {
		res = append(res, head.Val)
	}
	fmt.Println(res)
}

func main() {
	lists := []*ListNode{
		build([]int{1, 4, 5}),
		build([]int{1, 3, 4}),
		build([]int{2, 6}),
	}
	show(mergeKLists(lists)) // [1 1 2 3 4 4 5 6]
}
```

### 解法三：分治合并（最优）

像归并排序一样把链表数组对半分，两边各自合并成一条后再合并。每一层最多处理 N 个节点，共约 log k 层。注意单独处理长度为 0 和 1 的情况。

```go
package main

import "fmt"

type ListNode struct {
	Val  int
	Next *ListNode
}

// 合并两个升序链表，复用原节点
func mergeTwo(a, b *ListNode) *ListNode {
	dummy := &ListNode{}
	tail := dummy
	for a != nil && b != nil {
		if a.Val <= b.Val {
			tail.Next, a = a, a.Next
		} else {
			tail.Next, b = b, b.Next
		}
		tail = tail.Next
	}
	if a != nil {
		tail.Next = a // 接上剩余部分
	} else {
		tail.Next = b
	}
	return dummy.Next
}

// 解法三：分治，两半分别合并后再合并一次
func mergeKLists(lists []*ListNode) *ListNode {
	switch len(lists) {
	case 0:
		return nil
	case 1:
		return lists[0]
	}
	mid := len(lists) / 2
	return mergeTwo(mergeKLists(lists[:mid]), mergeKLists(lists[mid:]))
}

// 辅助函数：由切片建链表
func build(nums []int) *ListNode {
	dummy := &ListNode{}
	tail := dummy
	for _, x := range nums {
		tail.Next = &ListNode{Val: x}
		tail = tail.Next
	}
	return dummy.Next
}

// 辅助函数：打印链表
func show(head *ListNode) {
	res := []int{}
	for ; head != nil; head = head.Next {
		res = append(res, head.Val)
	}
	fmt.Println(res)
}

func main() {
	lists := []*ListNode{
		build([]int{1, 4, 5}),
		build([]int{1, 3, 4}),
		build([]int{2, 6}),
	}
	show(mergeKLists(lists)) // [1 1 2 3 4 4 5 6]
}
```

### 解法四：小根堆（最优）

堆中放每条链表当前的头节点，至多 k 个。每次弹出最小节点接到结果尾部，再把它的后继入堆。易错点：空指针不能入堆；应调用 heap.Push 和 heap.Pop，而不是直接调用类型上的同名方法。

```go
package main

import (
	"container/heap"
	"fmt"
)

type ListNode struct {
	Val  int
	Next *ListNode
}

// minHeap 按节点值组织的小根堆
type minHeap []*ListNode

func (h minHeap) Len() int           { return len(h) }
func (h minHeap) Less(i, j int) bool { return h[i].Val < h[j].Val }
func (h minHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }
func (h *minHeap) Push(x any)        { *h = append(*h, x.(*ListNode)) }
func (h *minHeap) Pop() any {
	old := *h
	n := len(old)
	node := old[n-1]
	*h = old[:n-1]
	return node
}

// 解法四：小根堆维护 k 个链表的当前头节点
func mergeKLists(lists []*ListNode) *ListNode {
	h := &minHeap{}
	for _, p := range lists {
		if p != nil { // 空链表不能入堆
			*h = append(*h, p)
		}
	}
	heap.Init(h) // 建堆 O(k)

	dummy := &ListNode{}
	tail := dummy
	for h.Len() > 0 {
		node := heap.Pop(h).(*ListNode) // 当前全局最小节点
		tail.Next = node
		tail = node
		if node.Next != nil {
			heap.Push(h, node.Next)
		}
	}
	return dummy.Next
}

// 辅助函数：由切片建链表
func build(nums []int) *ListNode {
	dummy := &ListNode{}
	tail := dummy
	for _, x := range nums {
		tail.Next = &ListNode{Val: x}
		tail = tail.Next
	}
	return dummy.Next
}

// 辅助函数：打印链表
func show(head *ListNode) {
	res := []int{}
	for ; head != nil; head = head.Next {
		res = append(res, head.Val)
	}
	fmt.Println(res)
}

func main() {
	lists := []*ListNode{
		build([]int{1, 4, 5}),
		build([]int{1, 3, 4}),
		build([]int{2, 6}),
	}
	show(mergeKLists(lists)) // [1 1 2 3 4 4 5 6]
}
```
