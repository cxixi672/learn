# 每日算法题 2026-11-27

## 第一题：和为 K 的子数组

- 题号：LeetCode 560
- 链接：https://leetcode.cn/problems/subarray-sum-equals-k/
- 编号：algo-20261127-01
- 难度：中等

**题目描述**：给定一个整数数组 nums 和一个整数 k，统计数组中和为 k 的子数组个数。子数组是数组中连续的非空元素序列。

示例：输入 nums = [1,1,1]，k = 2，输出 2；输入 nums = [1,2,3]，k = 3，输出 2。

数据范围：1 ≤ n ≤ 2×10⁴，-1000 ≤ nums[i] ≤ 1000，-10⁷ ≤ k ≤ 10⁷。

**解题思路**

数组里有负数，窗口扩大时和不一定变大、缩小时和不一定变小，所以滑动窗口不适用。从枚举所有区间出发，先去掉重复求和，再利用前缀和把问题改写为：对每个右端点，之前有多少个前缀和等于 pre - k。

| 解法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|---|---|---|---|
| 解法一：三重循环（暴力） | O(n³) | O(1) | 只适合很小的数组或用来对拍；本题数据范围会超时。 |
| 解法二：固定左端点累加 | O(n²) | O(1) | 不允许额外空间且 n 在万级时可用。 |
| 解法三：前缀和加哈希表（最优） | 平均 O(n) | O(n) | 面试标准答案；支持负数，也适用于数据流式的一次遍历。 |

### 解法一：三重循环（暴力）

枚举左端点 l 和右端点 r，再用第三层循环求 [l, r] 的和。

```go
package main

import "fmt"

// 解法一：枚举所有子数组，每个子数组重新求和
func subarraySum(nums []int, k int) int {
	count := 0
	for l := 0; l < len(nums); l++ {
		for r := l; r < len(nums); r++ {
			sum := 0
			for i := l; i <= r; i++ {
				sum += nums[i]
			}
			if sum == k {
				count++
			}
		}
	}
	return count
}

func main() {
	fmt.Println(subarraySum([]int{1, 1, 1}, 2)) // 2
	fmt.Println(subarraySum([]int{1, 2, 3}, 3)) // 2
}
```

### 解法二：固定左端点累加

[l, r] 的和等于 [l, r-1] 的和加 nums[r]，因此第三层循环可以省掉。注意找到一个满足条件的区间后不能提前退出，后面正负抵消还可能再次等于 k。

```go
package main

import "fmt"

// 解法二：固定左端点，右端点右移时累加
func subarraySum(nums []int, k int) int {
	count := 0
	for l := 0; l < len(nums); l++ {
		sum := 0
		for r := l; r < len(nums); r++ {
			sum += nums[r] // sum 是 [l, r] 的区间和
			if sum == k {
				count++ // 有负数，找到后不能 break
			}
		}
	}
	return count
}

func main() {
	fmt.Println(subarraySum([]int{1, 1, 1}, 2)) // 2
	fmt.Println(subarraySum([]int{1, 2, 3}, 3)) // 2
}
```

### 解法三：前缀和加哈希表（最优）

记 pre[i] 为前 i 个元素之和，子数组和为 pre[r] - pre[l]。要让它等于 k，就是找有多少个更早的 pre[l] 等于 pre[r] - k。边遍历边用哈希表记录每个前缀和出现的次数。两个易错点：初始要放入 0 出现 1 次（对应从下标 0 开始的子数组）；必须先查询再登记，否则 k = 0 时会把空子数组算进去。

手推 nums = [1,2,3]，k = 3：pre 依次为 1、3、6，分别查找 -2、0、3；后两次各命中 1 次，答案为 2。

```go
package main

import "fmt"

// 解法三：前缀和 + 哈希表计数
func subarraySum(nums []int, k int) int {
	seen := map[int]int{0: 1} // 前缀和 -> 出现次数；空前缀和为 0
	pre, count := 0, 0
	for _, x := range nums {
		pre += x
		count += seen[pre-k] // 先查询
		seen[pre]++          // 再登记，避免匹配到空子数组
	}
	return count
}

func main() {
	fmt.Println(subarraySum([]int{1, 1, 1}, 2)) // 2
	fmt.Println(subarraySum([]int{1, 2, 3}, 3)) // 2
}
```

## 第二题：课程表

- 题号：LeetCode 207
- 链接：https://leetcode.cn/problems/course-schedule/
- 编号：algo-20261127-02
- 难度：中等

**题目描述**：共有 numCourses 门课程，编号 0 到 numCourses-1。数组 prerequisites 中的 [a, b] 表示学习课程 a 之前必须先学完课程 b。判断能否学完所有课程。

示例：输入 numCourses = 2，prerequisites = [[1,0]]，输出 true；输入 numCourses = 2，prerequisites = [[1,0],[0,1]]，输出 false。

数据范围：1 ≤ numCourses ≤ 2000，0 ≤ prerequisites.length ≤ 5000，先修关系对互不相同。

**解题思路**

把课程看作节点、先修关系看作有向边 b 指向 a，能学完当且仅当图中没有环。可以按轮次直接模拟选课；也可以用 DFS 找回边；或者维护入度做拓扑排序，让模拟过程不再重复扫描。下表中 V 为课程数，E 为先修关系数。

| 解法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|---|---|---|---|
| 解法一：逐轮模拟（暴力） | O(V·(V+E)) | O(V) | 直观，小图可用；长链状依赖时每轮只能完成一门课。 |
| 解法二：DFS 三色标记 | O(V+E) | O(V+E) | 判环、需要定位环路径时方便；递归深度最多为 V。 |
| 解法三：Kahn 算法（推荐） | O(V+E) | O(V+E) | 迭代实现，顺带得到拓扑序；适合任务调度、依赖解析，可按层并行。 |

### 解法一：逐轮模拟（暴力）

每一轮先扫描所有先修关系，标记仍被阻塞的课程，再把其余未学的课程全部学完。某一轮没有任何进展就停止，检查是否全部学完。

```go
package main

import "fmt"

// 解法一：逐轮模拟，每轮学完所有当前没有阻塞的课程
func canFinish(numCourses int, prerequisites [][]int) bool {
	done := make([]bool, numCourses)
	finished := 0
	for {
		blocked := make([]bool, numCourses)
		for _, p := range prerequisites {
			if !done[p[1]] {
				blocked[p[0]] = true // 还有先修课没学完
			}
		}
		progress := false
		for c := 0; c < numCourses; c++ {
			if !done[c] && !blocked[c] {
				done[c] = true
				finished++
				progress = true
			}
		}
		if !progress {
			break // 这一轮没有任何进展
		}
	}
	return finished == numCourses
}

func main() {
	fmt.Println(canFinish(2, [][]int{{1, 0}}))         // true
	fmt.Println(canFinish(2, [][]int{{1, 0}, {0, 1}})) // false
}
```

### 解法二：DFS 三色标记

节点有三种状态：未访问、正在当前递归路径上、已完成。DFS 时遇到“正在路径上”的节点说明成环；遇到“已完成”的节点可以直接跳过。只用一个布尔 visited 数组无法区分这两种情况，会把菱形依赖误判为环。

```go
package main

import "fmt"

// 解法二：DFS 三色标记判环
func canFinish(numCourses int, prerequisites [][]int) bool {
	graph := make([][]int, numCourses)
	for _, p := range prerequisites {
		graph[p[1]] = append(graph[p[1]], p[0]) // 边：先修课 -> 后续课
	}
	const (
		unvisited = iota // 白：未访问
		visiting         // 灰：在当前递归路径上
		visited          // 黑：已确认无环
	)
	state := make([]int, numCourses)
	var dfs func(u int) bool // 返回 false 表示发现环
	dfs = func(u int) bool {
		state[u] = visiting
		for _, v := range graph[u] {
			if state[v] == visiting {
				return false // 回到路径上的节点，成环
			}
			if state[v] == unvisited && !dfs(v) {
				return false
			}
		}
		state[u] = visited
		return true
	}
	for i := 0; i < numCourses; i++ {
		if state[i] == unvisited && !dfs(i) {
			return false
		}
	}
	return true
}

func main() {
	fmt.Println(canFinish(2, [][]int{{1, 0}}))         // true
	fmt.Println(canFinish(2, [][]int{{1, 0}, {0, 1}})) // false
}
```

### 解法三：Kahn 算法（BFS 拓扑排序）

入度为 0 的课程可以立即学习。学完一门课就把它后续课程的入度减 1，减到 0 时入队。环上节点的入度永远减不到 0，所以最终出队数量小于 V 就说明有环。它与解法二复杂度相同，优势是不依赖递归，且直接给出学习顺序。

```go
package main

import "fmt"

// 解法三：Kahn 算法（BFS 拓扑排序）
func canFinish(numCourses int, prerequisites [][]int) bool {
	graph := make([][]int, numCourses)
	indegree := make([]int, numCourses) // 尚未完成的先修课数量
	for _, p := range prerequisites {
		graph[p[1]] = append(graph[p[1]], p[0])
		indegree[p[0]]++
	}
	queue := make([]int, 0, numCourses)
	for i, d := range indegree {
		if d == 0 {
			queue = append(queue, i)
		}
	}
	// 用下标 head 出队，循环结束时 queue 就是一个拓扑序
	for head := 0; head < len(queue); head++ {
		for _, v := range graph[queue[head]] {
			indegree[v]--
			if indegree[v] == 0 {
				queue = append(queue, v)
			}
		}
	}
	return len(queue) == numCourses
}

func main() {
	fmt.Println(canFinish(2, [][]int{{1, 0}}))         // true
	fmt.Println(canFinish(2, [][]int{{1, 0}, {0, 1}})) // false
}
```
